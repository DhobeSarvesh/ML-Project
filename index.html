Project Abstract & Motivation

Alzheimer's Disease is a progressive neurodegenerative disorder and the most common cause of dementia in older adults. Early detection before irreversible cognitive decline is essential for clinical management.

This lab project employs supervised machine learning models to classify disease risk using a multi-factor dataset combining demographic data, lifestyle patterns, cardiovascular indicators, and clinical cognitive scores (such as MMSE and ADL).

Data Pipeline & Preprocessing

  • 1
    Feature Pruning: Removed administrative columns PatientID and DoctorInCharge to prevent data leakage.
  • 2
    Data Split: Stratified 80:20 train-test split (1,719 training samples, 430 test samples, random_state=42).
  • 3
    StandardScaler: Fitted only on the 15 continuous numeric features of the training set to prevent test-set contamination.
  • 4
    SMOTE Balancing: Synthetic Minority Over-sampling Technique applied to the minority class in the training split.

Key Model Insights

Tree-Based Superiority: Gradient-boosted ensembles (XGBoost at 92.8% accuracy and 0.9417 ROC-AUC) and Random Forest (90.9% accuracy) significantly outperformed distance-based models (KNN at 63.3%).

Biomarker Dominance: Cognitive tests (MMSE score, Functional Assessment) and clinical indicators (ADL score, memory complaints) provided the highest predictive feature importance.
